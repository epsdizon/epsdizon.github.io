The problem

Every morning, nine forwarders send shipment reports in their own layouts: different column orders, dates typed as text, error values, and placeholder container numbers. Before the air and ocean dashboards could be refreshed, all of it had to be lined up by hand. Mistakes slipped through, and there was no quick way to see which forwarder's data needed fixing.

What I built

An Excel VBA tool run from one control workbook. One "Run all" button takes the morning's files through six steps, and stops with a clear message if any step fails, so a half-finished report never goes out.

  1. ConsolidateReads each forwarder's file, maps its layout to one standard format, repairs dates and error values, removes duplicate and stale bookings, and logs every fix.
  2. Refresh the dashboardsFills the air and ocean dashboards, adds lookups like fiscal week and service type, refreshes the pivots, and saves a template copy and an upload copy.
  3. Split out Sea-AirPulls sea-air shipments into their own file.
  4. Build the upload fileSplits shipments carrying several order references into one row per reference, ready for system upload.
  5. Score data qualityCounts errors per forwarder by unique shipment: missing order references, invalid MAWB or MBL numbers, missing or out-of-order milestones, and missing container numbers.
  6. Track the trendRolls the errors into a monthly view for each fiscal year, so improvement or slippage is visible.

What changed

The whole morning runs from one button. Every repair is written to a log, so any number on the dashboard can be traced back to the forwarder's original file. Each forwarder gets its own error file listing exactly which shipments to correct, instead of a general complaint.
